# ChatGPT Style Android launcher

A third-party Android launcher-style UI with Compose animations and automatic system light/dark theme.

Important: This is not an OpenAI official app and does not use private OpenAI APIs. It does not collect ChatGPT credentials. The login button opens https://chatgpt.com/ in Chrome Custom Tabs (or the default browser), where the user signs in and uses the official ChatGPT web experience. It cannot guarantee feature parity with the official Android app.

Build with Java 17 and Android SDK platform 35: `gradle assembleDebug`.
APK: `app/build/outputs/apk/debug/app-debug.apk`.
